# 批次 2 实施计划（内联图片 / 管理员改用户名 / 真删除账号 / 打开文件）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地批次 2 四个需求：A 聊天内联图片（`attachment_kind` 列 + preview/thumb 两条流式图片路由 + 缩略图 LRU + 灯箱）；B 管理员改用户名（PATCH 接口 + `profile.changed` 广播）；C 真删除账号（匿名占位行方案，消息匿名保留、群主群解散、事务清理、审计）；D 打开文件/文件夹（Tauri 与 Win7 壳三命令 open/reveal/check，只接受 taskId、由任务库反查路径）。

**Architecture:** 服务端在 `messages` 上加可空 `attachment_kind` 列（按附件扩展名判定），复用 documents 预览的 `documentImageReader` 逐块重鉴权模式新增 `/api/v1/files/{versionID}/preview|thumb` 路由（thumb 用 Go 标准库最近邻缩放 + 进程内 LRU 缓存，解码失败 302 回退原图）；管理员改名与删除都走 `accountTransaction` 事务模式，删除用全局唯一占位 users 行（`DELETED_USER_ID` 常量）吸收外键后真删行，群主被删时其创建的群解散但文件记录保留；桌面端新增 5 个 Tauri 命令（`file_attachment_preview`/`file_attachment_thumb`/`open_downloaded_file`/`reveal_downloaded_file`/`check_downloaded_files`），任务快照带出 `local_path`，打开命令由任务库反查路径作为白名单（前端永不传路径）；前端 `FileMessage` 按 `attachmentKind` 分流渲染缩略图 + 灯箱，聊天/传输/群文件三视图按"本地已完成下载且文件存在"分流打开按钮，`FileMissing` 错误回退下载按钮；Win7 壳 boundary/preload/main.cjs/native host 同步，逻辑与 Tauri 侧共享同一 transfer 模块源码。

**Tech Stack:** Go 1.26（net/http ServeMux、SQLite、`image`/`image/png`、`_ image/jpeg`、`_ image/gif`、`container/list` LRU）、React 18 + vitest + @testing-library/react、Tauri 2（windows crate `ShellExecuteW`）、legacy Electron shell（node:test）。

### 计划内偏离 spec 的点（已论证，执行时不要"纠正"回 spec 写法）

1. **审计 detail 不可实现**：`audit_events` 无自由文本列（schema 见迁移 006），"detail 记旧名→新名/被删 username"降级为仅记 action+target_id。
2. **群解散不删 groups 行**：`messages.group_id` 与 `files.group_id` 对 groups 是 RESTRICT 外键，且 `files` 的 CHECK 不允许把群文件的 group_id 置 NULL——保留 groups 行（成员、消息、file_memberships 全清空，会话从所有列表消失），群主改指占位行。解散系统消息取消：群解散后无任何成员能到达该会话，写入即死数据。spec 的核心承诺（文件与版本记录保留、消息不可达、会话消失）全部保持。
3. **upload_sessions 无 status 列**：spec 的 `SET status='cancelled'` 改为 `DELETE FROM upload_sessions WHERE user_id=?`（upload_receipts 级联清除），进行中会话自然作废。
4. **匿名化必须连 client_message_id 一起改写**：`messages UNIQUE(sender_id, client_message_id)` 是按发送者去重，多个被删用户共用 `m1` 之类 ID 时单改 sender_id 会撞唯一键——改写为 `'deleted:'||id`。
5. **用户名长度按字节 ≤256**（与 `validateCreateUser` 的 `len>256` 一致；spec 行文写"rune"，字节上限是既有语义）。
6. **thumb 缓存用 mutex+container/list 真 LRU**（256 条），spec 写的 `sync.Map` 无 LRU 淘汰语义。
7. **补 `UPDATE groups SET created_by=占位`**：groups.created_by 外键 RESTRICT，spec 未列此表，漏了则 `DELETE FROM users` 直接失败。
8. **A 需求 Win7 壳需要改**：legacy 壳不是普通浏览器（CSP `connect-src 'none'`、协议层拦截非 `linknestx-legacy://app/` 请求），spec"网页路径天然可用"不成立；legacy native host 补 `file_attachment_preview/thumb` 两命令保持四端一致。
9. **Tauri thumb 命令的 302**：reqwest 默认跟随重定向，302 会拿到原图字节（≤20MiB 时），与 spec"前端自己用 CSS 缩放"的意图一致；超 20MiB 返回错误，前端回退文件卡片。

```go
// uploadGroupFile publishes bytes as a group attachment (CompleteUpload routes
// through chat.AppendAttachment) and returns the version ID.
func uploadGroupFile(t *testing.T, f *socialFixture, group, name string, data []byte) string {
	t.Helper()
	ctx, e := f.a.AuthenticateContext(context.Background(), f.alice.AccessToken)
	if e != nil {
		t.Fatal(e)
	}
	sum := sha256.Sum256(data)
	// Tiny chunks force the preview reader to cross chunk boundaries.
	in := files.StartUploadInput{GroupID: group, Name: name, Size: int64(len(data)), SHA256: hex.EncodeToString(sum[:]), ChunkSize: 3}
	for start := 0; start < len(data); start += 3 {
		end := min(start+3, len(data))
		digest := sha256.Sum256(data[start:end])
		in.Chunks = append(in.Chunks, files.Chunk{Index: len(in.Chunks), Hash: hex.EncodeToString(digest[:]), Size: int64(end - start)})
	}
	u, e := f.fs.StartUpload(ctx, f.alice.UserID, in)
	if e != nil {
		t.Fatal(e)
	}
	for _, chunk := range in.Chunks {
		start := chunk.Index * 3
		if e = f.fs.PutChunk(ctx, f.alice.UserID, u.UploadID, chunk.Index, bytes.NewReader(data[start:start+int(chunk.Size)])); e != nil {
			t.Fatal(e)
		}
	}
	if _, e = f.fs.CompleteUpload(ctx, f.alice.UserID, u.UploadID); e != nil {
		t.Fatal(e)
	}
	return u.VersionID
}
```

```go
package http

import (
	"errors"
	"io"
	"net/http"
	"time"
)

// Preview streams original attachment image bytes under the same visibility
// rules as chunk downloads, without a size cap: the stream is chunked and each
// bounded write rechecks the current session and file ACL. Content is sniffed
// from the leading bytes so a renamed non-picture is rejected as 415 instead of
// becoming inline content.
func (h *FileHandlers) Preview(w http.ResponseWriter, r *http.Request) {
	actor := UserIDFromContext(r.Context())
	version := r.PathValue("versionID")
	m, e := h.Service.Manifest(r.Context(), actor, version)
	if e != nil {
		fileError(w, e)
		return
	}
	if m.Size == 0 || len(m.Chunks) == 0 {
		writeError(w, 415, errors.New("unsupported image type"))
		return
	}
	reader := &documentImageReader{ctx: r.Context(), service: h.Service, actor: actor, version: version, chunks: m.Chunks}
	defer reader.Close()
	prefix := make([]byte, 512)
	n, e := io.ReadFull(reader, prefix)
	if e != nil && e != io.EOF && e != io.ErrUnexpectedEOF {
		fileError(w, e)
		return
	}
	prefix = prefix[:n]
	kind := http.DetectContentType(prefix)
	switch kind {
	case "image/png", "image/jpeg", "image/gif", "image/webp":
	default:
		writeError(w, 415, errors.New("unsupported image type"))
		return
	}
	w.Header().Set("Content-Type", kind)
	w.Header().Set("Cache-Control", "no-store")
	w.Header().Set("X-Content-Type-Options", "nosniff")
	w.Header().Set("Content-Security-Policy", "default-src 'none'; sandbox")
	controller := http.NewResponseController(w)
	defer controller.SetWriteDeadline(time.Time{})
	buffer := make([]byte, 32*1024)
	write := func(b []byte) bool {
		if h.Service.CheckDownload(r.Context(), actor, version) != nil {
			return false
		}
		_ = controller.SetWriteDeadline(time.Now().Add(30 * time.Second))
		n, e := w.Write(b)
		return e == nil && n == len(b)
	}
	if !write(prefix) {
		return
	}
	for {
		n, e := reader.Read(buffer)
		if n > 0 && !write(buffer[:n]) {
			return
		}
		if e != nil {
			return
		}
	}
}
```

```go
// thumbLRU is an in-process thumbnail cache keyed by version ID. A single
// enterprise deployment keeps the working set small; overflow evicts the
// least-recently-used entry. sync.Map has no eviction semantics, hence the
// explicit list-backed map.
type thumbLRU struct {
	mu    sync.Mutex
	order *list.List
	items map[string]*list.Element
	limit int
}

type thumbValue struct {
	key   string
	bytes []byte
}

var attachmentThumbs = &thumbLRU{order: list.New(), items: map[string]*list.Element{}, limit: 256}

func (c *thumbLRU) get(key string) ([]byte, bool) {
	c.mu.Lock()
	defer c.mu.Unlock()
	if element, ok := c.items[key]; ok {
		c.order.MoveToFront(element)
		return element.Value.(*thumbValue).bytes, true
	}
	return nil, false
}
func (c *thumbLRU) put(key string, value []byte) {
	c.mu.Lock()
	defer c.mu.Unlock()
	if element, ok := c.items[key]; ok {
		c.order.MoveToFront(element)
		element.Value.(*thumbValue).bytes = value
		return
	}
	c.items[key] = c.order.PushFront(&thumbValue{key, value})
	for c.order.Len() > c.limit {
		oldest := c.order.Back()
		if oldest == nil {
			return
		}
		c.order.Remove(oldest)
		delete(c.items, oldest.Value.(*thumbValue).key)
	}
}
func (c *thumbLRU) len() int {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.order.Len()
}

const (
	thumbMaxEdge         = 480
	thumbMaxPixels       = 800_000_000
	thumbMaxSourceBytes  = 64 << 20
)

// Thumb serves a PNG thumbnail with the longest edge capped at 480. Sources
// the standard library cannot decode (including webp), oversized payloads and
// absurd pixel counts fall back to a 302 so the client scales the original in
// CSS. Access checks mirror Preview; cache hits still require a valid session
// because RequireAuth wraps the route.
func (h *FileHandlers) Thumb(w http.ResponseWriter, r *http.Request) {
	actor := UserIDFromContext(r.Context())
	version := r.PathValue("versionID")
	if cached, ok := attachmentThumbs.get(version); ok {
		serveThumb(w, cached)
		return
	}
	m, e := h.Service.Manifest(r.Context(), actor, version)
	if e != nil {
		fileError(w, e)
		return
	}
	if m.Size == 0 || m.Size > thumbMaxSourceBytes || len(m.Chunks) == 0 {
		redirectPreview(w, r, version)
		return
	}
	reader := &documentImageReader{ctx: r.Context(), service: h.Service, actor: actor, version: version, chunks: m.Chunks}
	defer reader.Close()
	data, e := io.ReadAll(io.LimitReader(reader, thumbMaxSourceBytes+1))
	if e != nil || int64(len(data)) != m.Size {
		redirectPreview(w, r, version)
		return
	}
	cfg, _, e := image.DecodeConfig(bytes.NewReader(data))
	if e != nil || int64(cfg.Width)*int64(cfg.Height) > thumbMaxPixels {
		redirectPreview(w, r, version)
		return
	}
	source, _, e := image.Decode(bytes.NewReader(data))
	if e != nil {
		redirectPreview(w, r, version)
		return
	}
	encoded := scaleToThumbnail(source)
	if len(encoded) == 0 {
		redirectPreview(w, r, version)
		return
	}
	attachmentThumbs.put(version, encoded)
	serveThumb(w, encoded)
}

func redirectPreview(w http.ResponseWriter, r *http.Request, version string) {
	w.Header().Set("Cache-Control", "no-store")
	http.Redirect(w, r, "/api/v1/files/"+version+"/preview", http.StatusFound)
}

func serveThumb(w http.ResponseWriter, encoded []byte) {
	w.Header().Set("Content-Type", "image/png")
	w.Header().Set("Content-Length", strconv.Itoa(len(encoded)))
	w.Header().Set("Cache-Control", "no-store")
	w.Header().Set("X-Content-Type-Options", "nosniff")
	w.Header().Set("Content-Security-Policy", "default-src 'none'; sandbox")
	w.Write(encoded)
}

// scaleToThumbnail resizes with nearest-neighbour sampling (standard library
// only; no x/image dependency) and re-encodes as PNG so gif first frames and
// every decodable source converge on one output type.
func scaleToThumbnail(source image.Image) []byte {
	bounds := source.Bounds()
	width, height := bounds.Dx(), bounds.Dy()
	if width <= 0 || height <= 0 {
		return nil
	}
	scale := float64(thumbMaxEdge) / float64(max(width, height))
	if scale > 1 {
		scale = 1
	}
	targetWidth, targetHeight := max(1, int(float64(width)*scale+0.5)), max(1, int(float64(height)*scale+0.5))
	target := image.NewRGBA(image.Rect(0, 0, targetWidth, targetHeight))
	for y := 0; y < targetHeight; y++ {
		sourceY := bounds.Min.Y + y*height/targetHeight
		for x := 0; x < targetWidth; x++ {
			target.Set(x, y, source.At(bounds.Min.X+x*width/targetWidth, sourceY))
		}
	}
	var out bytes.Buffer
	if png.Encode(&out, target) != nil {
		return nil
	}
	return out.Bytes()
}
```

```go
package auth

import (
	"context"
	"database/sql"
	"errors"
	"strings"
	"time"
	"unicode/utf8"
)

var ErrUsernameConflict = errors.New("username is already in use")

// usernameConflict reports SQLite guard failures that mean the requested name
// is taken: the users UNIQUE constraint or the username/account-number
// collision trigger installed by migrations 008/011.
func usernameConflict(err error) bool {
	if err == nil {
		return false
	}
	message := err.Error()
	return strings.Contains(message, "UNIQUE constraint failed: users.username") ||
		strings.Contains(message, "username collides with account number")
}

// UpdateUsername renames any account. Case-insensitive duplicates are rejected
// alongside the schema guards; sessions stay valid and contacts receive
// profile.changed only after commit.
func (s *AuthService) UpdateUsername(ctx context.Context, userID, username string) (User, error) {
	if err := validateAccountID(userID); err != nil {
		return User{}, err
	}
	username = strings.TrimSpace(username)
	if username == "" || len(username) > 256 || !utf8.ValidString(username) {
		return User{}, ErrInvalidInput
	}
	tx, actor, err := s.accountTransaction(ctx, true, false, true)
	if err != nil {
		return User{}, err
	}
	defer tx.Rollback()
	var current string
	err = tx.QueryRowContext(ctx, `SELECT username FROM users WHERE id=?`, userID).Scan(&current)
	if errors.Is(err, sql.ErrNoRows) {
		return User{}, ErrUserNotFound
	}
	if err != nil {
		return User{}, err
	}
	if current == username {
		if err = tx.Commit(); err != nil {
			return User{}, err
		}

		}
		return User{}, err
	}

		return User{}, err
	}
	if err = tx.Commit(); err != nil {
		return User{}, err
	}
	if s.profileChanged != nil {
		s.profileChanged(ctx, userID)
	}
	return s.repo.userByID(ctx, userID)
```

```go
package auth

import (
	"context"
	"database/sql"
	"errors"
	"time"

// DELETED_USER_ID is the shared tombstone account. Hard deletions re-point
// history at it so rows stay referable while the personal account is gone. The
// account is disabled and never issues sessions.
const DELETED_USER_ID = "e59ec6d2-8d67-4f14-9a1c-2b6d0f5a4c31"

var (
	ErrCannotDeleteSelf = errors.New("cannot delete the current administrator account")
	ErrAdminProtected   = errors.New("administrators must be removed from the admin role before deletion")
)

// UserDeletion summarizes a committed deletion so the router composer can
// refresh affected clients; the auth package stays free of the event hub.
type UserDeletion struct {
	DeletedUser   string
	Conversations []string
	Peers         []string
}

func (s *AuthService) SetUserDeletedHandler(handler func(context.Context, UserDeletion)) {
	s.userDeleted = handler
}

// DeleteUser hard-deletes one non-administrator account in a single
// transaction. History is anonymised onto the tombstone (client_message_id is
// rewritten alongside sender_id because the per-sender uniqueness key would
// otherwise collide across deleted users), groups owned by the target are
// dissolved — members, messages and file memberships are cleared while file
// and version records survive with tombstone attribution — friendships and
// direct conversations disappear for both sides, and the users row is removed
// with cascades taking devices, sessions, roles, reads and peer sources.
//
// The dissolved groups row itself is retained: messages and files hold
// RESTRICT foreign keys to it and the files CHECK constraint forbids moving
// group files elsewhere, so keeping the empty row is the only way to honour
// "files are never deleted".
func (s *AuthService) DeleteUser(ctx context.Context, userID string) error {
	if err := validateAccountID(userID); err != nil {
		return err
	}
	tx, actor, err := s.accountTransaction(ctx, true, false, true)
	if err != nil {
		return err
	}
	defer tx.Rollback()
	if userID == actor.user.ID {
		return ErrCannotDeleteSelf
	}
	if userID == DELETED_USER_ID {
		return ErrInvalidInput
	}
	var targetAdmin bool
	err = tx.QueryRowContext(ctx, `SELECT EXISTS(SELECT 1 FROM user_roles ur JOIN roles r ON r.id=ur.role_id WHERE ur.user_id=users.id AND r.name='admin') FROM users WHERE id=?`, userID).Scan(&targetAdmin)
	if errors.Is(err, sql.ErrNoRows) {
		return ErrUserNotFound
	}
	if err != nil {
		return err
	}
	if targetAdmin {
		return ErrAdminProtected
	}
	direct := map[string]bool{}
	if rows, e := tx.QueryContext(ctx, `SELECT group_id FROM direct_conversations WHERE pair_low=? OR pair_high=?`, userID, userID); e == nil {
		for rows.Next() {
			var id string
			if rows.Scan(&id) == nil {
				direct[id] = true
			}
		}
		rows.Close()
	}
	dissolved := []string{}
	if rows, e := tx.QueryContext(ctx, `SELECT id FROM groups WHERE created_by=? AND id NOT IN(SELECT group_id FROM direct_conversations)`, userID); e == nil {
		for rows.Next() {
			var id string
			if rows.Scan(&id) == nil {
				dissolved = append(dissolved, id)
			}
		}
		rows.Close()
	}
	dissolvedSet := map[string]bool{}
	for _, id := range dissolved {
		dissolvedSet[id] = true
	}
	shared := []string{}
	if rows, e := tx.QueryContext(ctx, `SELECT group_id FROM group_members WHERE user_id=?`, userID); e == nil {
		for rows.Next() {
			var id string
			if rows.Scan(&id) == nil && !direct[id] && !dissolvedSet[id] {
				shared = append(shared, id)
			}
		}
		rows.Close()
	}
	peers := []string{}
	seenPeer := map[string]bool{}
	if rows, e := tx.QueryContext(ctx, `SELECT CASE WHEN pair_low=? THEN pair_high ELSE pair_low END FROM friendships WHERE ? IN(pair_low,pair_high) UNION SELECT CASE WHEN pair_low=? THEN pair_high ELSE pair_low END FROM direct_conversations WHERE ? IN(pair_low,pair_high)`, userID, userID, userID, userID); e == nil {
		for rows.Next() {
			var id string
			if rows.Scan(&id) == nil && !seenPeer[id] {
				seenPeer[id] = true
				peers = append(peers, id)
			}
		}
		rows.Close()
	}
	now := s.now().UTC().Format(time.RFC3339Nano)
	if _, err = tx.ExecContext(ctx, `INSERT INTO users(id,username,email,password_hash,disabled,must_change_password,created_at,updated_at) VALUES(?,'deleted-user','','',1,1,?,?) ON CONFLICT(id) DO NOTHING`, DELETED_USER_ID, now, now); err != nil {
		return err
	}
	if _, err = tx.ExecContext(ctx, `INSERT INTO profiles(user_id,account_number,display_name) VALUES(?,NULL,'已注销用户') ON CONFLICT(user_id) DO NOTHING`, DELETED_USER_ID); err != nil {
		return err
	}
	for _, group := range dissolved {
		if _, err = tx.ExecContext(ctx, `DELETE FROM messages WHERE group_id=?`, group); err != nil {
			return err
		}
		if _, err = tx.ExecContext(ctx, `DELETE FROM file_memberships WHERE group_id=?`, group); err != nil {
			return err
		}
		if _, err = tx.ExecContext(ctx, `DELETE FROM group_members WHERE group_id=?`, group); err != nil {
			return err
		}
	}
	if _, err = tx.ExecContext(ctx, `UPDATE messages SET sender_id=?,client_message_id='deleted:'||id WHERE sender_id=?`, DELETED_USER_ID, userID); err != nil {
		return err
	}
	for _, statement := range []string{
		`UPDATE files SET created_by=? WHERE created_by=?`,
		`UPDATE file_versions SET created_by=? WHERE created_by=?`,
		`UPDATE documents SET author_id=? WHERE author_id=?`,
		`UPDATE groups SET created_by=? WHERE created_by=?`,
	} {
		if _, err = tx.ExecContext(ctx, statement, DELETED_USER_ID, userID); err != nil {
			return err
		}
	}
	if _, err = tx.ExecContext(ctx, `DELETE FROM upload_sessions WHERE user_id=?`, userID); err != nil {
		return err
	}
	if _, err = tx.ExecContext(ctx, `DELETE FROM group_members WHERE user_id=?`, userID); err != nil {
		return err
	}
	if _, err = tx.ExecContext(ctx, `DELETE FROM friend_requests WHERE from_id=? OR to_id=?`, userID, userID); err != nil {
		return err
	}
	if _, err = tx.ExecContext(ctx, `DELETE FROM friendships WHERE pair_low=? OR pair_high=?`, userID, userID); err != nil {
		return err
	}
	if _, err = tx.ExecContext(ctx, `DELETE FROM direct_conversations WHERE pair_low=? OR pair_high=?`, userID, userID); err != nil {
		return err
	}
	if _, err = tx.ExecContext(ctx, `DELETE FROM users WHERE id=?`, userID); err != nil {
		return err
	}
	if err = RecordAudit(ctx, tx, actor.user.ID, "account.deleted", userID, s.now()); err != nil {
		return err
	}
	if err = tx.Commit(); err != nil {
		return err
	}
	if s.userDeleted != nil {
		conversations := append(append([]string{}, dissolved...), shared...)
		s.userDeleted(ctx, UserDeletion{DeletedUser: userID, Conversations: conversations, Peers: peers})
	}
	return nil
}
```

```rust
#[tauri::command]
pub async fn file_attachment_preview(
    state: tauri::State<'_, NativeState>,
    version_id: String,
) -> Result<String> {
    use base64::Engine;
    crate::transfer::models::segment(&version_id)?;
    let owner = state.auth.owner().await?;
    let response = state
        .auth
        .request_for(
            &owner,
            "GET",
            &format!("/api/v1/files/{version_id}/preview"),
            None,
            false,
        )
        .await?;
    let mime = response
        .headers()
        .get(reqwest::header::CONTENT_TYPE)
        .and_then(|v| v.to_str().ok())
        .unwrap_or("")
        .split(';')
        .next()
        .unwrap_or("")
        .to_owned();
    if !matches!(
        mime.as_str(),
        "image/png" | "image/jpeg" | "image/gif" | "image/webp"
    ) {
        return Err(TransferError::new("此附件不支持图片预览"));
    }
    let bytes = crate::auth::session::limited_body(response, 256 * 1024 * 1024).await?;
    if state.auth.owner().await? != owner {
        return Err(TransferError::new("登录账户已更改"));
    }
    Ok(format!(
        "data:{};base64,{}",
        mime,
        base64::engine::general_purpose::STANDARD.encode(bytes)
    ))
}

pub async fn file_attachment_thumb(
    state: tauri::State<'_, NativeState>,
    version_id: String,

    use base64::Engine;

    // scale in CSS.
    let mime = response
        .headers()
        .get(reqwest::header::CONTENT_TYPE)
        .and_then(|v| v.to_str().ok())
        .unwrap_or("")
        .split(';')
        .next()
        .unwrap_or("")
        .to_owned();
    if !matches!(
        mime.as_str(),
        "image/png" | "image/jpeg" | "image/gif" | "image/webp"
    ) {
        return Err(TransferError::new("缩略图不可用"));
    }
    let bytes = crate::auth::session::limited_body(response, 20 * 1024 * 1024).await?;
    if state.auth.owner().await? != owner {
        return Err(TransferError::new("登录账户已更改"));
    }
    Ok(format!(
```

在 `external.rs` 的 `pub fn open` 之后追加（与 checked_url 完全独立；只接受绝对路径，调用方是任务库反查）：

```rust
// Local-file launching is deliberately separate from checked_url, which must
// keep rejecting file paths. The only callers resolve absolute paths from the
// transfer task library, so the path itself is the whitelist.
pub fn open_local_path(path: &str) -> Result<()> {
    let target = std::path::Path::new(path);
    if path.is_empty() || !target.is_absolute() {
        return Err(TransferError::new("文件路径无效"));
    }
    #[cfg(target_os = "macos")]
    {
        let status = std::process::Command::new("/usr/bin/open")
            .arg(target)
            .stdin(std::process::Stdio::null())
            .stdout(std::process::Stdio::null())
            .stderr(std::process::Stdio::null())
            .status()?;
        if status.success() {
            return Ok(());
        }
    }
    #[cfg(target_os = "windows")]
    {
        use windows::{
            core::PCWSTR,
            Win32::UI::{Shell::ShellExecuteW, WindowsAndMessaging::SW_SHOWNORMAL},
        };
        let verb: Vec<u16> = "open\0".encode_utf16().collect();
        let destination: Vec<u16> = path.encode_utf16().chain(std::iter::once(0)).collect();
        let result = unsafe {
            ShellExecuteW(
                None,
                PCWSTR(verb.as_ptr()),
                PCWSTR(destination.as_ptr()),
                None,
                None,
                SW_SHOWNORMAL,
            )
        };
        if result.0 as isize > 32 {
            return Ok(());
        }
    }
    Err(TransferError::new("无法打开文件"))
}

pub fn reveal_local_path(path: &str) -> Result<()> {

    if path.is_empty() || !target.is_absolute() {
        return Err(TransferError::new("文件路径无效"));
    }
```

```rust
pub async fn check_downloaded_files(
    state: tauri::State<'_, NativeState>,
    task_ids: Vec<String>,
) -> Result<serde_json::Map<String, serde_json::Value>> {
    if task_ids.len() > 200 {
        return Err(TransferError::new("检查任务过多"));
    }
    let owner = state.auth.owner().await?;
    let mut result = serde_json::Map::new();
    for task_id in task_ids {
        if crate::transfer::models::segment(&task_id).is_err() {
            result.insert(task_id, serde_json::Value::Bool(false));
            continue;
        }
        let exists = state
            .transfers
            .download_task_path(&owner, &task_id)
            .ok()
            .filter(|path| local_path_exists(path))
            .is_some();
        result.insert(task_id, serde_json::Value::Bool(exists));
    }
    Ok(result)
}
```
