# LinkNestX 0.2 本地交付记录

完成日期：2026-11-10。本记录对应 0.2 本地开发验收时点，仅涉及本地开发、测试和打包；没有连接或更新企业服务器，没有更改原 Nginx。当时原有 Git 暂存内容与工作开始前逐字节一致，工作保留在开发分支，尚未提交、推送或合并。后续仓库发布不表示企业部署已完成。

## 本期实现

- 限制版 Web 登录、群聊/私聊、好友、已读与文件下载；单文件最多 1 GB，服务端拒绝 Web 上传、原生分片/P2P、管理写操作和更新。局域网普通 HTTP 实际验证通过。
- 数字账号、头像/资料、好友申请通过后私聊。前台实际可见消息才标记已读；私聊显示未读/已读，群聊查看已读人数及成员。
- 新聊天界面、文件待发送列表、可信原生拖放/粘贴入口、消息内传输进度与独立传输中心；显示速率、预计剩余、完成用时和平均速率。旧任务缺失历史明确标为期间统计。
- 桌面服务器内置；默认参与授权的多源文件传输，没有员工共享开关。已完成任务可再次保存文件，重复下载时优先显示当前任务。
- 内置签名增量更新、后台准备、全局就绪提示、传输期间延后安装、经过校验的全量回退、可信独立助手、原子替换和原子回滚。失败原因持续保留，可明确重试。
- 公开客户端下载页、离线签名发布工具、真实更新资产和下一次部署材料。企业知识库等未来模块未加入空占位页面。
