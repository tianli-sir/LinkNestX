# LinkNestX 使用说明

本说明适用于 0.3 版本。实际可用功能取决于企业服务器和客户端是否都已升级；由管理员完成部署后再分发对应客户端。

## 安装和登录

0.1 需要手动升级一次。从企业工作区的 `/downloads` 页面下载对应系统的实际安装包。macOS 建议放入当前用户的 `Applications` 文件夹，以便以后直接在软件内更新；Windows 使用当前用户安装方式。

Windows 10/11 使用标准版；Windows 7 SP1 使用与系统匹配的 32 位或 64 位兼容版。兼容版自带运行环境，不需要单独安装 WebView2，安装包请向管理员获取。详见 [Windows 安装说明](windows-compatibility.md)。

打开桌面客户端，只需输入管理员分配的用户名或数字账号及密码。服务器已经内置。新员工第一次登录需要设置自己的密码；没有账号时联系管理员创建。

## 联系人和已读

在“我的资料”中查看、复制自己的数字账号；桌面端可更换展示名和头像。在“联系人”按数字账号查找同事、发送好友申请，对方接受后即可私聊。也可以点击消息旁的头像查看资料。

自己发出的私聊消息显示“未读”或“已读”，群聊显示已读人数，点击可查看名单。只有对方在前台实际看到消息才会记为已读；后台收到消息不会自动计入。群聊名单按当前有权访问该消息的成员统计，不包含发送者。

## 聊天与文件

桌面端可把文件拖入聊天区，或使用粘贴文件/截图、添加文件。文件先进入待发送列表，可移除，再点击“发送”。文字可用 Ctrl + Enter（macOS 为 ⌘ + Enter）发送。

文件卡片直接显示任务进度、当前速率和预计剩余时间；“传输”页面集中管理全部任务，可暂停、继续或重试。完成后查看用时和平均速率。老版本任务缺失的历史统计不会补成虚假总用时，恢复后的测量会单独说明。已完成的文件仍可另存一次。

普通文件默认保留 30 天，到期由系统删除；管理员放入公共文件池的文件长期保留，所有已登录员工可下载。单个桌面文件最大 20 GB。关闭桌面窗口后应用留在系统托盘，任务仍能继续；从托盘退出才结束应用。

## 文档与公共知识区

打开“文档”，在“知识动态”查看同事分享的教程、记录和经验。“我的文档”管理自己创建的内容，“草稿箱”保存尚未发布的内容，“公共文档”集中展示管理员收录的知识。

点击“写文档”可用 Markdown 编写标题、列表、表格和链接，并随时切换预览。可见范围包括“仅自己”“好友可见”和“全员可见”；草稿始终只对作者可见。保存期间编辑入口暂时锁定，避免覆盖未提交内容。若内容发生冲突，编辑器保留自己的文字，可查看最新版本再决定如何合并。

桌面端先保存草稿，再添加附件、拖入文件或粘贴截图；上传完成后点击“插入正文”生成图片或下载链接。文档附件使用与聊天文件相同的传输流程，但**文档和文档附件长期保留**，不受普通聊天文件 30 天到期规则影响。外部网站链接仍在浏览器打开。

管理员可以把已发布、全员可见的文档加入公共区。收录后的正文和附件由管理员维护，原作者不能编辑或删除；移出公共区后恢复作者管理。公共区和附件仅供已登录员工使用，不提供匿名分享。删除好友后，双方失去对彼此“好友可见”文档的访问权限。

## 外观主题

在工作区右上角或“设置 → 外观”选择浅色、深色或跟随系统。设置保存在当前设备，桌面端和网页版分别记住各自的选择。

## 网页版

在管理员提供的企业工作区地址后访问 `/app/`（例如 `https://files.example.com/app/`），即可登录、聊天、查看已读与好友、编写 Markdown 文字文档、浏览和下载单个不超过 1 GB 的文件。网页版不上传文件，不提供客户端后台传输或自动更新。下载交给浏览器处理，在浏览器下载列表确认保存结果；需要大文件和完整体验时使用桌面端。

## 软件更新

标准版客户端在后台检查并准备新版本，完成后在工作区提示。打开更新设置，选择“重启并更新”；正在传输时会延后，待任务结束再确认。更新无法启动时恢复旧版本并保留失败说明，可以明确选择重试。手动安装一次 0.2 后，后续发布才适用此流程。

Windows 7 兼容版暂时使用完整安装包更新：先完成传输，从托盘退出，再运行新版兼容安装包。

连接地址由管理员在打包时内置。以后更换服务器或使用公网域名时，通过新版客户端一起更新连接地址，无需员工自行填写。
