02 / MAKE YOURSELF AT HOME

三步，回到你的工作区。

客户端已内置企业服务地址，
使用员工账号登录即可开始。

  1. 01 / DOWNLOAD

    选择设备版本

    Windows 在“设置 → 系统 → 关于”查看系统类型。Mac 在苹果菜单的“关于本机”中确认是 Apple 芯片还是 Intel 处理器。

  2. 02 / INSTALL

    完成客户端安装

    Windows 打开安装包，按提示完成安装；ZIP 便携版请先完整解压。Mac 打开 DMG，将应用放入当前用户的 Applications 文件夹。

  3. 03 / CONNECT

    登录团队工作区

    打开 LinkNestX，使用员工账号和密码登录。客户端已内置企业服务地址；没有账号或忘记密码，请联系团队管理员。

不确定该选哪一个？

Windows 10 / 11 的日常安装优先选择 EXE；MSI 可用于需要该格式的安装流程。Windows 7 SP1 请对应系统的 32 位或 64 位，便携版无需安装。

安装时遇到系统提示？

请先确认文件来自当前团队的下载页，并核对 SHA-256。若系统仍阻止安装，将提示信息发送给管理员，确认适用的安装方式。
